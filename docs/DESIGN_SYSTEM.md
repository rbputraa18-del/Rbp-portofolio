# PORTFOLIO — DESIGN SYSTEM

## Personality
**Editorial + Cinematic + Technology + Warmth**

## Colors
- Background: deep charcoal / near-black
- Primary text: warm off-white
- Accent: muted amber / warm gold
- Secondary surfaces: slightly lighter neutral charcoal

Keep the palette restrained. Exact tokens can be finalized during implementation.

## Typography
Use two complementary families:
- expressive editorial/display font for hero and major headings
- clean readable sans-serif for body, metadata, navigation and controls

## Layout
- generous whitespace
- strong alignment
- controlled content width
- editorial asymmetry where useful
- large project imagery
- clear hierarchy

## Navigation
Desktop: `REKHA | WORK | ABOUT | CONTACT | EN/ID`  
Mobile: `REKHA | MENU`

Keep navigation minimal and sticky.

## Hero
Use the supplied portrait as the main visual. Integrate it into the composition rather than treating it as a CV headshot.

Hero must communicate:
1. identity
2. role
3. value proposition
4. next action

## Projects
Use large screenshots, varied image/text alignment, numbering, metadata, and restrained hover effects. RE17 receives the largest treatment.

## Buttons
Clear, compact, high-contrast, subtle hover motion. Avoid oversized pill buttons everywhere.

## Motion
Preferred:
- fade/slide reveals
- subtle image scale
- language-switch animation
- restrained parallax
- page transitions
- section reveal

Avoid decorative continuous movement, scroll-jacking, heavy particles, or slow interactions. Respect reduced-motion preferences.

## Imagery
Project screenshots are evidence. Use consistent image treatment, subtle borders/shadows, and meaningful alt text. Never fabricate screenshots.

## Responsive
Mobile is a first-class layout:
- readable typography
- comfortable touch targets
- clear project hierarchy
- fast images
- accessible navigation
- no horizontal overflow

## Accessibility
Maintain sufficient contrast, keyboard navigation, visible focus states, semantic HTML, meaningful alt text, reduced-motion support, accessible language toggle, and accessible mobile menu.

## Restraint
If an effect does not improve understanding, interaction, or identity, remove it.
