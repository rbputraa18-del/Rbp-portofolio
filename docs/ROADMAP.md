# PORTFOLIO — ROADMAP

## Guiding Rule
Build in small, reviewable milestones. Do not implement the entire portfolio in one uncontrolled pass.

## Phase 0 — Project Discovery
- inspect framework
- inspect package manager
- inspect dependencies
- inspect structure
- inspect assets
- inspect routes
- inspect styling
- identify risks

Output: discovery report only.

## Phase 1 — Foundation
- confirm project structure
- establish design tokens
- establish global typography
- establish base layout
- establish responsive foundation
- establish content structure
- establish language architecture

Acceptance: stable foundation, without final visual polish.

## Phase 2 — Navigation + Hero
- sticky navbar
- mobile navigation
- EN/ID switch
- hero typography
- portrait integration
- hero CTA

Acceptance: responsive, language switch works, approved hierarchy.

## Phase 3 — Homepage Core
- philosophy
- selected work
- project previews
- how I build
- AI development

Acceptance: all five projects represented and editorial presentation works.

## Phase 4 — About + Contact
- about
- currently building
- contact CTA
- footer

Acceptance: clear identity and contact path.

## Phase 5 — Case Studies
Build one case study first: **RE17 Control**.

Then adapt for:
- Personal OS
- KodingID
- Maw Inventory
- Web UMKM

Acceptance: Problem → Thinking → Solution → Interface → Role → Technology → Status/Result.

## Phase 6 — Visual Refinement
- spacing
- typography
- imagery
- hover states
- motion
- responsive polish
- accessibility

## Phase 7 — QA
Test desktop, tablet, mobile, navigation, language persistence, routes, images, keyboard navigation, reduced motion, broken links, console errors, and production build.

## Phase 8 — Deployment
Choose target, configure, build, deploy, and test production URL.

## Phase 9 — Final Review
Review from Product, Design, and Technical perspectives. Only then consider the first public version complete.
